# Evidence index

All images in this folder are sanitized copies prepared for portfolio use.

- `extension-interface/`: extension popup and score breakdown.
- `threat-assessment/`: report screenshots showing URL intelligence, page content analysis, whitelist/impostor detection, and score calculation.
- `dashboard-monitoring/`: anonymized security dashboard overview illustrating threat monitoring, agent activity, reports, and security statistics.

The safe-result examples demonstrate the interface only. They do not establish phishing-detection success. Dashboard identities and flagged-domain details have been redacted.
